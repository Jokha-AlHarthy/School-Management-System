# 🎓 School Management System

A Java console-based School Management System built to demonstrate core Object-Oriented Programming (OOP) concepts.

## ✨ Features

- Manage students and teachers
- Add, view, and search students
- Inheritance & polymorphism
- Method overloading & overriding
- Encapsulation & validation
- Interfaces

## 🛠️ Technologies

- Java
- Object-Oriented Programming (OOP)
- Collections

## 📁 Project Structure

```text
entities      → Person, Student, Teacher
interfaces    → Displayable, Manageable, Searchable
services      → StudentService
utils         → HelperUtils, InputHandler
main          → SchoolApp
